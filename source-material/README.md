# Source material

Drop every factual document for the portfolio in this folder:

- resume / CV
- bios (short and long)
- project write-ups
- images (headshot, project screenshots)
- anything containing links, metrics, quotes, or dates the site should show

These files are the complete universe of facts for the site — every name,
date, employer, project, metric, skill, quote, and link on the site must
trace back to a file here. Once documents land, the full Phase 1 plan runs:
content inventory, site map, and three design directions derived from what
the documents show you actually do.
